# docs/product/ — the overall view

This folder holds the **product-level view of AI QA Studio**: where it is headed and
why. It is **direction, not specification** — it states the goal and leaves the *how*
to GitHub issues.

## What's here

| Doc | Holds |
|-----|-------|
| [00_Vision_and_Scope.md](00_Vision_and_Scope.md) | The vision, the repos it binds, the problem it solves, the guidelines, and scope |

## How to use it

- This is a **goal.** When direction changes, edit it — don't let it harden into a spec.
- Implementation detail belongs in a **GitHub issue**, not here.

## Relationship to stories

`docs/product/` is the whole; [`docs/stories/`](../stories/) holds individual feature
requests — each a goal that advances this view. A story says what a user needs and why;
the *how* is worked out on the GitHub issue.
